========================================
BACKEND API
========================================

URL Base: https://todo-list.dobleb.cl

Endpoints implementados:
- POST /auth/login - Iniciar sesión
- POST /auth/register - Registrar usuario
- GET /todos - Listar tareas del usuario
- POST /todos - Crear tarea
- PATCH /todos/:id - Actualizar tarea
- DELETE /todos/:id - Eliminar tarea
- POST /images - Subir imagen (multipart/form-data)

========================================
INSTRUCCIONES DE EJECUCIÓN
========================================

1. Clonar repositorio
2. npm install --legacy-peer-deps
3. Verificar archivo .env (ya incluido)
4. npm start
5. Escanear QR con Expo Go o usar emulador

========================================
TESTING
========================================

Para probar la aplicación:
1. Registrar un nuevo usuario (cualquier email + contraseña 4+ caracteres)
2. O usar credenciales de prueba si existen en el backend
3. Crear tareas con foto y ubicación
4. Editar, completar y eliminar tareas
5. Verificar sincronización con backend (pull-to-refresh)
6. Cerrar sesión y verificar que se limpia el token
